# 隐私说明

生效日期：2026 年 7 月 29 日

XHS Clipper 只在用户打开一篇小红书图文笔记并主动点击扩展后处理该页面。扩展没有开发者服务器、账号系统、广告 SDK 或数据分析服务。

## 扩展读取的数据

对于用户当前打开的笔记，XHS Clipper 可能读取标题、正文、作者信息、标签、时间、互动数据、来源链接、图片地址，以及 OCR 所需的图片内容。扩展不会在后台浏览博主主页、采集评论或抓取其他笔记。

## 本地处理

OCR 使用扩展内置模型在 Chrome 中运行。图片和识别文字不会发送给远程 OCR 服务。图片数据只会读入内存用于识别，不会导出为图片文件。

扩展可能在 Chrome 本地扩展存储中保存 OCR 开关、最近一次 OCR 任务、识别文字、图片地址和 Obsidian API Key。Obsidian 笔记目录和本地 API 地址可能通过 Chrome 扩展同步保存，供用户自己的 Chrome 配置继续使用。XHS Clipper 的开发者不会收到这些同步数据。

## 数据输出

只有用户主动选择输出操作时，数据才会离开扩展：

- “复制”会把 Markdown 写入系统剪贴板。
- “下载”会通过 Chrome 保存 Markdown 文件。
- “写入 Obsidian”会把 Markdown 和访问凭据发送到用户配置的本机回环地址。扩展只接受 `127.0.0.1` 和 `localhost`。

为了显示和读取笔记，浏览器会正常访问小红书页面及其图片服务地址。这些服务适用各自的隐私政策。

## 保存与删除

XHS Clipper 不在远程服务器保存采集内容。用户可以在 Chrome 扩展设置中清除本地数据，也可以通过卸载扩展删除这些数据。已经下载的 Markdown 和写入 Obsidian 的笔记由用户自行管理。

## 变更与联系

隐私说明发生重要变化时，项目会在仓库中记录。问题可以提交到项目的 [GitHub Issues](https://github.com/LinkisLethe/xhs-clipper/issues)。
