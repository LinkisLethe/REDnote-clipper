# 隐私说明

生效日期：2026 年 8 月 24 日

XHS Clipper 会在小红书页面中显示悬浮工作台。文章页会准备当前笔记；首页、搜索结果和博主主页只有在用户点击“扫描当前页”后才会扫描。插件仅在用户选择文章并确认设置后开始剪藏。扩展没有开发者服务器、账号系统、广告 SDK 或数据分析服务。

## 扩展读取的数据

准备当前文章或扫描小红书页面时，XHS Clipper 可能读取当前标签页中的文章链接、标题，以及页面可见的作者名和缩略图。插件不会自行滚动页面或加载更多结果。

对于当前打开或用户选择的文章，XHS Clipper 可能读取标题、正文、作者信息、标签、时间、互动数据、来源链接、图片地址，以及 OCR 所需的图片内容。批量任务会用非活动标签页逐篇打开并处理所选文章，处理后关闭标签页。扩展不会采集评论、读取无关标签页，也不会处理用户没有选择的文章。

## 本地处理

OCR 使用扩展内置模型在 Chrome 中运行。图片和识别文字不会发送给远程 OCR 服务。图片数据只会读入内存用于识别，不会导出为图片文件。

Chrome 本地扩展存储可能保存 OCR 设置、进行中的 OCR 任务、悬浮工作台偏好、当前批量队列，以及最多 200 条已完成剪藏记录。完成记录包含文章 ID、标题、链接、文件名、导出类型和完成时间，用来在列表中标记已经处理过的文章。Obsidian API Key 也保存在本地。任务结束后，临时 OCR 任务中的图片识别文字会被清除。

Obsidian 笔记目录和本地 API 地址可能通过 Chrome 扩展同步保存，供用户自己的 Chrome 配置继续使用。XHS Clipper 的开发者不会收到这些同步数据。

## 数据输出

只有用户主动选择输出操作时，数据才会离开扩展：

- “复制”会把 Markdown 写入系统剪贴板。
- “下载”会通过 Chrome 保存 Markdown 文件。
- “写入 Obsidian”会把 Markdown 和访问凭据发送到用户配置的本机回环地址。扩展只接受 `127.0.0.1` 和 `localhost`。

为了显示和读取笔记，浏览器会正常访问小红书页面及其图片服务地址。这些服务适用各自的隐私政策。

## 保存与删除

XHS Clipper 不在远程服务器保存采集内容。用户可以在 Chrome 扩展设置中清除偏好、任务记录和完成历史，也可以通过卸载扩展删除这些数据。已经下载的 Markdown 和写入 Obsidian 的笔记由用户自行管理。

## 变更与联系

隐私说明发生重要变化时，项目会在仓库中记录。问题可以提交到项目的 [GitHub Issues](https://github.com/LinkisLethe/xhs-clipper/issues)。
