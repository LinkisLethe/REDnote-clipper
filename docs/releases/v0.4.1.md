# XHS Clipper v0.4.1

这个版本主要解决图片较多时 OCR 任务越跑越卡的问题。

## 安装

1. 在 Assets 中下载 `xhs-clipper-v0.4.1.zip`，不要下载 GitHub 自动生成的 Source code 压缩包。
2. 解压后打开 `chrome://extensions/`，启用开发者模式。
3. 点击“加载已解压的扩展程序”，选择解压得到的 `xhs-clipper-v0.4.1` 文件夹。

直接安装不需要 Node.js 或 pnpm。

## 本次更新

- 大任务不再为每次图片进度复制和持久化完整 OCR 历史。
- OCR 文字排版完成后移除逐行坐标，保留最终文本和任务恢复信息。
- 长图直接分块生成 `ImageData`，省去 PNG 重编码和再次解码。
- 每轮推理结束后主动释放 ONNX 输入与输出 Tensor。
- 增加真实 Chrome OCR 基准和大任务状态压力测试。

固定的 80 张图片、每张 80 行测试中，累计状态处理耗时从 8,586.77 ms 降至 229.95 ms，最终任务状态从 1,183,503 B 缩小到 359,343 B。真实 Chrome OCR 连续运行 12 轮，识别 12 次全部成功，后段没有变慢。

详细数据和复测命令见 [性能测试记录](https://github.com/LinkisLethe/xhs-clipper/blob/v0.4.1/docs/PERFORMANCE.zh-CN.md)。

## English

This release reduces UI and storage overhead during large OCR jobs. It sends lightweight progress patches, compacts processed OCR geometry, streams long-image tiles as `ImageData`, and disposes ONNX tensors after inference. The release also adds repeatable browser OCR and job-state benchmarks.

Download `xhs-clipper-v0.4.1.zip` from Assets, extract it, and load the extracted folder from `chrome://extensions/`. Node.js and pnpm are not required.
