# XHS Clipper v1.0.0

v1.0.0 把原有的单篇采集扩展为可控的批量剪藏工作台，同时保留弹窗里的单篇采集、Markdown 预览和本地 OCR。

## 安装

1. 在 Assets 中下载 `xhs-clipper-v1.0.0.zip`，不要下载 GitHub 自动生成的 Source code 压缩包。
2. 解压后打开 `chrome://extensions/`，启用开发者模式。
3. 点击“加载已解压的扩展程序”，选择解压得到的 `xhs-clipper-v1.0.0` 文件夹。
4. 刷新安装前已经打开的小红书页面。

直接安装不需要 Node.js 或 pnpm。

从旧版升级时，如果想保留当前扩展 ID 和本地设置，可以把新文件覆盖到 Chrome 已加载的旧目录，再点击扩展卡片上的“重新加载”。如果直接加载新的版本文件夹，请先停用或移除旧版，避免页面出现两个悬浮面板。

## 本次更新

- 在首页、搜索结果、博主主页和文章页使用悬浮剪藏工作台。
- 扫描当前页面已经加载的笔记，按标题关键词筛选，单批最多选择 20 篇。
- 逐篇显示打开、提取、OCR 和导出状态，并估算剩余时间。
- 支持在当前文章完成后停止，不会直接中断正在写入的结果。
- 批量任务可选择 Chrome 下载或写入 `Clippings/XHS`。
- Obsidian 遇到重复笔记时，可以跳过、另存为新版本或覆盖同一来源的原笔记。
- 本地 OCR 支持全部图片、跳过封面和自定义页码；自定义页码会提前显示预计识别张数。
- 浮窗会记住 OCR、导出位置、设置分区和收起状态，完成提示会自动消失。
- 修复连续任务需要刷新、重复放大会偏移、达到 20 篇后仍可勾选等问题。

自动剪藏会用非活动标签页逐篇打开所选文章。平台规则和风控可能变化，建议控制批量大小，避免短时间反复运行；遇到登录验证或验证码时立即停止。

## English

v1.0.0 adds a floating batch-clipping workspace while keeping the existing single-post popup, editable Markdown preview, and local OCR.

The workspace runs on Xiaohongshu home, search, creator, and post pages. It scans only post cards already loaded in the current tab, supports all-keyword title filtering, and accepts up to 20 explicitly selected posts per batch. Selected posts are processed one at a time in inactive tabs.

Batch jobs now show per-post stages and time estimates, can stop after the current post, and can download Markdown or write to the shared `Clippings/XHS` Obsidian folder. Duplicate Obsidian notes can be skipped, saved as a new version, or overwritten after the source ID is checked. OCR supports all images, skipping the cover, or a custom page range with an estimated image count.

Download `xhs-clipper-v1.0.0.zip` from Assets, extract it, and load the extracted folder from `chrome://extensions/`. Reload any Xiaohongshu tabs that were open before installation. Node.js and pnpm are not required.

To preserve the extension ID and local settings during an upgrade, copy the new files over the directory Chrome already loads, then select **Reload** on the extension card. If you load the new version folder as a separate extension, disable or remove the old copy first so two floating panels do not appear.
