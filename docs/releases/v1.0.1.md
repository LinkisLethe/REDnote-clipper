# XHS Clipper v1.0.1

v1.0.1 统一了插件入口。旧的单篇采集弹窗已经移除，点击 Chrome 工具栏中的 XHS Clipper 图标会直接打开或收起悬浮工作台。

## 安装

1. 在 Assets 中下载 `xhs-clipper-v1.0.1.zip`，不要下载 GitHub 自动生成的 Source code 压缩包。
2. 解压后打开 `chrome://extensions/`，启用开发者模式。
3. 点击“加载已解压的扩展程序”，选择解压得到的 `xhs-clipper-v1.0.1` 文件夹。
4. 刷新安装前已经打开的小红书页面。

直接安装不需要 Node.js 或 pnpm。

从 v1.0.0 升级时，可以把新文件覆盖到 Chrome 当前加载的旧目录，再点击扩展卡片上的“重新加载”。这样会保留扩展 ID、Obsidian 设置和浮窗偏好。直接加载新的版本文件夹前，请先停用或移除旧版。

## 本次更新

- 点击插件图标即可打开或收起悬浮工作台。
- 在文章页展开工作台时，插件会重新准备当前文章。
- 浮窗脚本失效时会尝试重新加载；仍然失败时，插件图标会显示错误标记。
- 移除旧单篇弹窗、Markdown 预览编辑器和不再需要的剪贴板权限。
- 清理旧弹窗使用的翻译、测试和截图，缩小设置页面脚本。
- README、隐私说明和权限说明已经改为当前工作台流程。

本地 OCR、Chrome 下载、Obsidian 导出、自定义页码和最多 20 篇的任务限制保持不变。

## English

v1.0.1 unifies the extension entry point. The old single-post popup has been removed. Selecting the XHS Clipper button in the Chrome toolbar now opens or collapses the floating workspace.

On an article page, opening the workspace prepares the current post again. If the workspace script is unavailable, the extension tries to reload it and shows an error badge if that fails. This release also removes the unused clipboard permission and the old popup files, translations, tests, and screenshot.

Local OCR, Chrome downloads, Obsidian export, custom OCR page ranges, and the 20-post task limit are unchanged.

Download `xhs-clipper-v1.0.1.zip` from Assets, extract it, and load the extracted folder from `chrome://extensions/`. Reload Xiaohongshu tabs that were open before installation. Node.js and pnpm are not required.

To preserve the extension ID and local settings when upgrading from v1.0.0, copy the new files over the directory Chrome already loads, then select **Reload** on the extension card. Disable or remove the old copy before loading the new version as a separate extension.
